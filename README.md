# 🧪 المختبر الافتراضي للفيزياء - السنة الرابعة متوسط (4AM)

تطبيق ويب تفاعلي ومحاكي تعليمي لمادة العلوم الفيزيائية، مصمم لطلاب السنة الرابعة متوسط للمساعدة في فهم وتجسيد المفاهيم الفيزيائية والظواهر الكهربائية بطريقة مبسطة وتفاعلية.

---

### 🌟 مميزات المختبر:
1. **⚡ محاكاة الظواهر الكهربائية (التكهرب):**
   * تجسيد التكهرب بالدلك، اللمس، والإصلاء (التأثير).
   * عرض الشحنات الكهربائية الموجبة والسالمة وحركة ورقتي الكشاف الكهربائي في الوقت الحي.
2. **📐 محاكاة قانون أوم (Ohm's Law):**
   * التحكم التفاعلي في قيم التوتر $U$ والمقاومة $R$.
   * حساب شدة التيار $I$ تلقائياً مع تمثيل الدارة.
3. **🛡️ تطبيق الأمن الكهربائي:**
   * توضيح دور المأخذ الأرضي والمنصهرة لحماية الأفراد والأجهزة.
